## Part 8-5. 물리엔진 기반 실시간 이벤트 시뮬레이터 · 시계열/SDS 속성 트래킹 및 `Zoro-1` 자율 대응(Auto-Response) 기획 (`docs/powerplant-physics-auto-plan.md`)

1.2GW 화력발전소의 열역학·유체역학·전력 계통을 모사하는 **경량 물리엔진(Lumped-Parameter Physics Engine)으로 실제 발전소와 동일한 연쇄 이상 이벤트를 발생**시키고, 각 설비·간선의 속성 변화를 **시계열 및 SDS(Selective Decision/State) 로직으로 실시간 추적**하여, **`Zoro-1` 결정 모델이 안전 가드레일 안에서 즉각적인 자동화 대응(Auto-Mitigation)까지 수행**하는 엔드투엔드(E2E) 자율 관제 기획입니다.

### 3. 물리엔진(Physics Engine) 설계: 실제 상황처럼 이벤트를 발생시키는 원리

가짜 고정 텍스트를 띄우는 것이 아니라, `synthetic_db.json`의 마인드맵(`equipments`, `edges`) 위에서 **3가지 물리 법칙이 매 틱(100ms)마다 돌아가며 각 설비의 속성값을 실제로 변화**시킵니다.

#### 3.1 마인드맵 간선(`Edge`)을 따라 흐르는 3대 물리 방정식

1. **유체역학 (압력-유량-밸브 개도 관계)**:
* 펌프 토출 압력 $P_{\text{pump}}$와 밸브 개도율 $u \in [0, 1]$에 따른 통과 유량 $Q$ 및 상류 배압(Back-pressure):

$$Q(t) = C_v \cdot u(t) \cdot \sqrt{\max(0, P_{\text{up}}(t) - P_{\text{down}}(t))}$$

* **실제 현상 재현**: `103동 급수조절밸브` 개도 $u(t)$가 $0.78 \rightarrow 0.18$로 고착되면 즉시 유량 $Q$가 급감하고, 빠져나가지 못한 물 때문에 상류 `주급수펌프 A`의 토출 압력 $P_{\text{up}}$이 $+0.9\text{ MPa}$ 치솟으며 진동(`CY001`)이 함께 증가합니다.

2. **배관 이류 지연 (Advection Delay $\Delta t$)**:
* 배관 길이 $L$과 유속 $v$에 의해 상류의 유량 변화가 하류 설비에 도달하기까지 물리적 시간 지연 $\tau = L / v$ (예: $4.2\text{초}$)가 걸립니다.

3. **열역학 및 회전기계 동역학 (보일러 온도 & 터빈 진동)**:
* 보일러 과열기 온도 변화율($dT/dt$)은 연소열 유입($\dot{Q}_{\text{fire}}$)과 냉각 급수 유량($Q_{\text{fw}}$)의 차이로 결정됩니다:

$$C_{\text{th}} \frac{dT_{\text{steam}}}{dt} = \dot{Q}_{\text{fire}} - c_p \cdot Q_{\text{fw}}(t - \tau) \cdot (T_{\text{steam}} - T_{\text{in}})$$

* **실제 현상 재현**: 상류 밸브가 막히고 정확히 $\tau = 4.2\text{초}$ 뒤부터 `101동 보일러 과열기`의 온도 상승 기울기($dT/dt$)가 $+6.6^\circ\text{C/s}$로 치솟으며 트립 한계($635^\circ\text{C}$)를 향해 달려갑니다.

#### 3.2 카오스/이벤트 발생기 (Fault & Event Injector)

관제 콘솔 상단(또는 자동 시나리오 러너)에서 다음 **5가지 실전 이벤트**를 언제든 실시간으로 터뜨릴 수 있습니다:

* **`Event 1 [기계적 고착]`**: `103동 급수조절밸브` 포지셔너 18% 고착 주입 ➔ 유량 급감 ➔ 4.2초 뒤 101동 보일러 과열 연쇄 발생
* **`Event 2 [센서 드리프트/노이즈]`**: `102동 고압터빈` 압력 전송기 A에만 $-11.8\text{ MPa}$ 바이어스 주입 (실제 물리 압력은 정상 유지)
* **`Event 3 [전력 계통 탈락]`**: `104동 6.9kV 차단기` 과전류 트립 주입 ➔ 상용 급수펌프 정지 ➔ 예비 펌프 자동 기동(Auto-Start) 테스트
* **`Event 4 [윤활유 냉각 불량]`**: `102동 1층 윤활유 냉각기` 열교환 효율 50% 저하 주입 ➔ 베어링 유온 상승 ➔ 고압터빈 축진동 $210\ \mu\text{m}$ 급등
* **`Event 5 [복합 동시 사고]`**: 상류 밸브 미세 누설 + 하류 센서 노이즈 동시 발생

### 4. 시계열 & SDS 속성 트래킹 메커니즘 (State Tracking Matrix)

물리엔진이 매 100ms마다 갱신하는 설비 속성들은 시계열-SDS 통합 상태 테이블(`AttributeTracker`)에서 아래 4단계 상태로 실시간 추적됩니다.

```text

+---------------------------------------------------------------------------------------------------+
| KKS 속성 키        : 10LAB20AA102.valve_open_pct (103동 2F 주급수 유량조절밸브 개도율)            |
| 현재 물리값 x(t)   : 18.0 % (설계 정상치: 78.0 %)                                                 |
| 시계열 미분 지표   : 속도(dx/dt) = -30.0 %/s | 가속도(d²x/dt²) = +15.0 %/s² | 분산(Var) = 420.5   |
| 변곡점 타임스탬프  : t0 = 14:20:00.000 (최초 급락 감지 시각 — 마인드맵 Δt 계산의 기준 앵커!)      |
| SDS 상태 전이 코드 : [STABLE] ──(t=0.0s)──► [SLEW_DROP] ──(t=+2.0s)──► [STUCK_LOW_BOTTLENECK]     |
| 연결 간선 전파 추적: 하류 10HAH10BB001.steam_temp_c 에 Δt = +4.2s 시차로 열적체 전파 확인 (Match) |
+---------------------------------------------------------------------------------------------------+

```

1. **평시 (`SDS::Stable`)**: 변화율 $\vert{}dx/dt\vert{}$가 데드밴드 이내이면 링버퍼에만 조용히 기록하고 AI 모델을 호출하지 않습니다(VRAM 및 연산 0% 소비).
2. **변곡점 포착 (`SDS::InflectionDetected`)**: $\vert{}dx/dt\vert{}$가 임계치를 돌파하는 순간 해당 시각($t_0$)을 설비 속성에 스탬핑하고, 연결된 상·하류 마인드맵 노드들의 시계열 감시 주기를 최고 해상도로 높입니다.
3. **인과 사슬 결합 (`SDS::CausalChainLocked`)**: 하류 노드에서 연이어 변곡점($t_1, t_2$)이 찍히면, 간선 속성(`lag_secs_range`)과 비교해 **`[원인 노드(t0) ➔ 파급 노드(t1)]` 인과 체인**을 하나로 묶어 `Zoro-1` 판단 프롬프트로 직송합니다.
4. **회복 추적 (`SDS::Recovering` ➔ `Stable`)**: `Zoro-1`의 자동화 제어 명령이 물리엔진에 투입된 후, 기울기($dx/dt$)의 부호가 반전되어 정상 범위로 수렴하는지 끝까지 추적합니다.

### 5. `Zoro-1` 결정 모델을 통한 자율 대응(Auto-Response) 설계 (`policy.rs` 확장)

기존 `core/src/policy.rs`는 자동 확정 조건으로 `Auto 모드 ∧ 승인자·법령근거 기록 ∧ 유리한 처분(Favorable) ∧ Gate 1~3 규칙 통과 ∧ Zoro-1 확신도 ≥ 0.95`를 강제하고 있습니다.
발전소에서는 이 원칙을 그대로 계승하여 **‘설비를 멈추지 않고 정상 운전 상태를 회복시키는 안전 완화 조치(Mitigation)’를 `OutcomeClass::Favorable`로 매핑**함으로써 `policy.rs`의 안전 철학을 100% 유지한 채 자동화 대응을 수행합니다!

#### 5.2 `Zoro-1`이 자동화 대응을 확정하기까지의 4중 안전 검증 (0.63초 이내 완료)

자동화 모드(`OperatingMode::Auto`)가 켜져 있을 때 Tier 1 자율 제어가 발동하려면 아래 4단계를 모두 통과해야 합니다:

1. **선행 인터록 규칙 통과 (`gates_clear == true`)**: 상류(`Depth -1`) 압력과 우회 배관 상태가 안전 조건을 만족하는지 결정론적 규칙으로 먼저 확인합니다.

2. **SDS 3축 직교 분할 질문 (`judge_by_criteria`)**: `Zoro-1`(`jev_head`)에게 **① 시계열 인과 시차($\Delta t$) 부합성, ② 물리량 증감 방향 일치성, ③ 우회 제어 시 하류 안전성** 3가지를 개별 질문합니다.

3. **최소 확신도 문턱값 통과 (`min_confidence >= 0.95`)**: 3개 질문 중 **가장 낮은 확률이 `0.95` 이상**일 때만 `Disposition::AutoFinalize`가 떨어집니다.

4. **사후 샘플 감사 표기 (`post_audit_rate = 10%`)**: 자동 실행된 제어 건 중 10%(사건 ID의 SHA-256 해시 기준)는 교대감독 콘솔에 `[사후 샘플 감사 대상]` 배지를 붙여 인간이 사후 복기하도록 강제합니다.

### 7. 기존 로드맵(P11 ~ P14)에의 통합 구현 포인트

이 물리엔진 시뮬레이터와 `Zoro-1` 자율 제어 루프는 외부 무거운 물리 라이브러리 없이 **순수 Rust 표준 라이브러리(`std::thread`, `f64` 미분 연산) 약 250줄**로 `zorogravity-core` 안에 깔끔하게 구현됩니다:

1. **`core/src/physics.rs` (신규 — 경량 발전소 물리엔진 & 이벤트 주입기)**:
* `Lattice`의 설비 노드와 간선을 읽어 매 100ms마다 압력·유량·온도·진동 상태를 업데이트하는 `PlantSimulator::tick(dt)` 함수와 고장 주입기(`inject_fault`)를 구현합니다.

2. **`core/src/sds.rs` (신규 — 시계열 링버퍼 & SDS 변곡점 트래커)**:
* `tick(dt)`에서 나온 속성값들의 기울기($dx/dt$), 잔여 시간(TTF), 간선 전파 시차($\Delta t$)를 추적하다가 변곡점 발생 시 자동으로 `Engine::run()`을 트리거합니다.

3. **`core/src/policy.rs` & `pipeline.rs` (자동화 제어 피드백 연결)**:
* `Disposition::AutoFinalize`가 떨어지면 감사 로그(`AuditCategory::AutoFinalized`)를 남김과 동시에 `PlantSimulator::apply_mitigation(control_cmd)`를 호출하여 물리엔진의 우회 밸브를 실제로 열어 온도를 안정화시킵니다.
