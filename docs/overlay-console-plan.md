> 상태: 받은 2차 개선안(① 풀스크린 오버레이 전환 · ② 자연어 질의를 하단 허브 커맨드 바로)을 코드와 대조해 구현한 기록입니다. 실측은 [verification.md](verification.md) 11절입니다.
> 참고한 화면: noto-sandbox `ui/` 의 `layout.css` · `overlay.css` · `hud.css` · `cctv.css`, `cctv.js`(말풍선 자리 잡기) · `overlays.js`(ESC 순서) · `command-bar.js`(입력줄).
> 앞 단계 기록: [cctv-console-plan.md](cctv-console-plan.md) (CCTV형 통합 관제판). 그 화면의 6 : 4 격자 분할을 이 문서의 무대로 바꿨습니다.

- **무대**: `.stage` 는 `position: relative` 한 칸이고 그 안에서 고른 뷰가 `.canvas-full { position: absolute; inset: 0 }` 로 깔립니다. 판은 모두 그 위에 뜹니다. 층 순서는 도면(0) < CCTV 말풍선(5) < 확대 단추 · A0 미니맵(6) < 코너 · 결재 HUD(8) < 허브(9) < 서랍(20) < 팝오버(25) < 확대 모달(100) 이고, 허브에 Drop-up 이 열려 있으면 서랍보다 위(22)로 올라갑니다 (물리엔진 서랍을 연 채 질의해도 결과가 보이게).
- **도면 맞춤**: 도면 · A0 · Mermaid 는 무대에서 결재 HUD 폭(340 px + 여백)과 첫 줄 알약(48 px)을 뺀 빈 자리에 비율을 지켜 맞춥니다 (`cctv/stage.ts` 의 `fitRect`). 그 위에 휠 확대(커서 자리 고정) · 끌어 이동 · 두 번 누르기 맞춤을 겁니다 (`usePanZoom`). 끌다 놓은 클릭은 버려서 이동 끝에 설비가 눌리지 않습니다. 휠은 무대에서 받아 말풍선 위에서 굴려도 도면이 확대되고, HUD · 허브 · 팝오버 위에서는 그 판이 스크롤됩니다.
- **결재 HUD 접기**: `[접기 ▸]` 를 누르면 제목 줄(병목 수 · 🔒 다음 Step · 트립 잔여)만 남고, 무대에서 `has-hud` 가 빠져 허브 · 서랍 · 도면 맞춤 · 마인드맵 중심이 오른쪽까지 넓어집니다 (noto-sandbox `.stage.has-unit`).
- **ESC** 는 화면에 겹친 순서대로 맨 위 판부터 하나씩 닫습니다: 파형 확대 → 설정 → 사건 대기열 → 질의 결과 → 차트 → 서랍 → 검색 적중 표시 → 설비 선택 (noto-sandbox `overlays.js` 의 STACK). 질의 결과판 · 차트는 열리면 서랍 위로 올라오므로 서랍보다 먼저 닫힙니다. 질의 줄에 글이 있으면 ESC 는 글만 지웁니다. **Enter · /** 는 어디서든 질의 줄로 들어갑니다 (`/` 는 글 칸이 아닐 때, Enter 는 단추를 누르는 키이기도 하니 빈 곳에서만).

## 3. 하지 않은 것 · 남은 과제

- CCTV 카드의 스캔 조각 타일: 콘솔 사건 상세에 스캔 그림 · 조각 좌표가 없어 도면 조각으로 대신했습니다. 넣으려면 `incident_detail` 이 현장 보고마다 줄인 그림과 항목별 조각 상자(단말 스캔 회신과 같은 것)를 보내야 합니다.
- 1920 × 1009 창에서는 도면이 높이에 묶입니다 (도면 2000 : 1400 = 1.43, 빈 자리 1544 × 923 = 1.67). 그래서 결재 HUD 를 접어도 도면은 커지지 않고 가운데로 옮겨 갈 뿐입니다 (11절). 더 크게 보려면 휠 확대를 씁니다.
- 허브(약 145 px)가 도면 아래쪽(운전 기준치 일람표 · 표제란)을 덮습니다. 설비 상자는 도면 위 2/3 에 있어 가리지 않지만, 표를 보려면 끌어 올립니다.
- 마인드맵은 확대 · 이동을 붙이지 않았습니다 (노드 끌기와 겹침). A0 는 타일 확대를 그대로 씁니다.
