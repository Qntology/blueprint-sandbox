# CCTV형 통합 관제판 (개선안: 3-Way 도면 + 시계열 · SDS 로직 차트 상시 동기화)

> 상태: 받은 개선안(Part 1 ~ 4)을 코드와 대조해 구현한 기록입니다. 수치는 합성 데이터 기준이고 실측은 [verification.md](verification.md) 10절입니다.
> **2차 개선안으로 화면 틀을 바꿨습니다**: 아래 0절의 6 : 4 격자 분할은 풀스크린 무대 + 떠 있는 유리 HUD 로, 설비 칩은 지시선 CCTV 말풍선으로 바뀌었습니다 ([overlay-console-plan.md](overlay-console-plan.md)). 이 문서의 1절(데이터 · 오버레이 내용 · 전처리)은 그대로 유효합니다.
> 참고한 화면: noto-sandbox 의 "교통 지도식 CCTV" (전체 맵 위에 로봇마다 카메라 카드를 지시선으로 붙이고, 우측 HUD · 하단 허브를 겹친 화면).
> blueprint 에서는 같은 문법을 **도면 위 설비마다 SDS 상태 칩 · 미니 파형을 붙이고**, 화면을 녹화 표시(● REC) · 채널 번호(CAM-01 ~ 03) · OSD 정보가 있는 칸으로 나누는 방식으로 옮겼습니다.

## 0. 화면 구성 (`app/src/OfficerView.tsx`)

```
┌ 머리: 제목 · [🏭 화력발전소 | 🖥️ AI 데이터센터] · 검색 · 🚨 트립(셧다운) 잔여 TTF · 교대감독 · 자동화 · 시뮬레이터 · 물리엔진 ┐
│ 공간 Depth: Lv1 ▸ Lv2 ▸ Lv3 ▸ Lv4 ▸ Lv5                                                                              │
├ 대기열 ─┬ ● CAM-01 3-Way 도면 모니터 (P&ID·MEP / Mermaid / 마인드맵)   [60 %] ─────────────┬ 통합 병목 · 결재창 ─┤
│ 확인 대기 │  설비 상자: SDS 상태 칩 + 기울기 + 미니 파형, 원인 경로 배관: Δt (허용 범위 ✓)   │ 🚨 감지된 핵심 병목   │
│ 처리 완료 ├ ● CAM-02 시계열 로직 차트 [40 %] ─────┬ ● CAM-03 SDS 로직 차트 ───────────────┤ 인터록 신호등 게이트 │
│           │  D-1 역류 · D0 원인 · D+n 경보 파형    │ ① 상태 전이 ② 3축 분할(최솟값) ③ 벡터  │ 표준 조치 요약 · 결재 │
│           │  + 링버퍼 지표 (변곡 · 기울기 · TTF)   │                                        │ 선택 설비 · 이슈 트리 │
├───────────┴────────────────────────────────────────┴────────────────────────────────────────┴──────────────────────┤
│ Stage 1 ~ 5 카드 + 마이닝 레인 (건수 · ⏳ 최대 대기)   ← 예전 단계 바 · 마이닝 레인 두 줄을 한 줄로                       │
│ ⏪ 타임머신 리플레이 (발원점 · 분석 시각 · 재생) — 모든 칸이 같은 시각 t                                                │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

선택 설비(`selectedKks`)와 재생 시각(`t`) 하나로 모든 칸이 움직입니다: 도면 · Mermaid · 마인드맵 어디서 눌러도, SDS 로직 차트의 전이 줄을 눌러도 선택이 바뀌고, 타임 스크러버를 움직이면 도면 칩 · 마인드맵 링 · 시계열 커서 · SDS 전이(재생 시각까지만 켜짐)가 함께 바뀝니다. 5초마다 사건 목록을 새로 받을 때 재생 시각을 되돌리지 않게 했습니다 (예전에는 상세를 새로 받을 때마다 분석 시각으로 돌아감).

## 2. 하지 않은 것 · 남은 과제

- A0 종합 뷰(`A0View`)에는 SDS 칩을 얹지 않았습니다 (타일 격자 화면이라 설비 상자가 작음, 선택 · 원인 · 경보 강조는 그대로).
- 카메라 카드처럼 도면 밖에 떠서 지시선으로 잇는 카드(noto-sandbox 식)는 도면이 화면을 꽉 채워 둘 자리가 없어, 상자에 붙은 칩으로 대신했습니다. → 2차 개선안에서 구현 ([overlay-console-plan.md](overlay-console-plan.md)).
- 대조 카드의 조각이 칸보다 넓은 문제: 칸 단위 좌표가 필요하면 gocr 표 출력의 행 순서와 잉크 행 띠를 맞춰 잘라야 합니다.
